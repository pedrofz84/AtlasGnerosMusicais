Criado por Pedro Silva · pedro-silva.com · github.com/pedrofz84

O Atlas dos Géneros Musicais é uma visualização interativa da história e evolução da música através dos séculos e continentes.

Cada nó representa um género; cada ligação, uma relação de parentesco, influência ou fusão. Os dados cobrem 396 géneros de todas as épocas e regiões do mundo.

Tecnologias

  • D3.js v7 — simulação de forças e renderização SVG
  • HTML / CSS / JS puros — sem framework nem build step
  • Google Fonts — Space Mono, Outfit

Licença

MIT — dados e código disponíveis para uso livre.

Grafo de rede

  • Clique num nó — abre painel de detalhes e realça conexões
  • Arrastar um nó — repositiona-o na simulação
  • Scroll / pinch — zoom in/out
  • Clique no fundo — desseleccionar
  • Botões +/−/⊡ — zoom e centrar tudo

Filtros e pesquisa

  • A pesquisa filtra por nome e descrição, ignorando acentos
  • Clicar na legenda filtra por categoria (clique novamente para remover)
  • O menu "Era" restringe a um período histórico
  • "Fusões visíveis" mostra/esconde as ligações de fusão

Vistas

  • Grafo — rede de forças interativa e navegável
  • Árvore — géneros organizados por categoria com pesquisa interna por secção

Porque é que os géneros estão em posições aparentemente aleatórias?
A posição de cada nó é calculada por simulação de forças física — géneros relacionados atraem-se mutuamente. Não há coordenadas fixas; o layout emerge das relações entre géneros.
O que significam as diferentes cores e estilos das linhas?
Linhas brancas/cinzentas = parentesco ou influência. Linhas amarelas tracejadas = fusão (géneros híbridos). As setas indicam a direção da influência.
O grafo não carrega — aparece uma mensagem de erro.
O projeto precisa de ser servido por um servidor HTTP local. Não funciona ao abrir o ficheiro directamente (file://). Use python -m http.server 8000 ou a extensão Live Server do VS Code.
Posso descarregar os dados para uso próprio?
Sim. Clique em ⬇ Exportar JSON nos controlos para descarregar todos os géneros e ligações em formato JSON. Os dados são disponibilizados sob licença MIT.
Como navego para um género a partir do painel de detalhes?
Clique em qualquer etiqueta de género no painel de detalhes (secções "Fusões" e "Relacionados") para centrar o grafo nesse nó e realçar as suas conexões.
